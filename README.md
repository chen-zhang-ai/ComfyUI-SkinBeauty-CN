# ComfyUI-SkinBeauty-CN

面向人物参考图的中文肤色美白节点包。目标是把偏黄/偏暖肤色自然调整为冷白皮，同时尽量保护背景、服装、高光和皮肤纹理。

## 节点

### 人物肤色美白｜参数面板（中文）

一套参数可以同时连接多个处理节点。内置：

- 关闭
- 低档·自然提亮
- 中档·自然冷白
- 高档·通透冷白
- 冷白皮
- 粉润白
- 奶油白

可继续调整总强度、美白、冷暖、红润、匀肤、暗部提亮、高光保护、饱和度、平滑、纹理保留、肤色识别和蒙版羽化。

### 人物肤色美白｜处理＋预览（中文）

输入/输出遵循 ComfyUI 的 `IMAGE` 批次格式，因此一个接口能处理一张或多张同尺寸图。输出包括：

1. 美白图像
2. 肤色蒙版
3. 预览图（保持原始宽高，可继续接下游）
4. 中文处理报告

处理节点只保留真实算法预览，不再使用容易把背景近似调白的浏览器模拟：

- **自动精确预览**：默认开启“实时精确预览”；调节节点272任意参数后，停止操作约0.5秒即自动调用后端真实算法，不运行视频节点。
- **手动精确预览**：“刷新精确预览（不跑视频）”用于更换参考图后强制刷新，具有悬停、按压、处理中与完成反馈。
- **节点内左右对比**：原图与精确结果叠放在同一大画布内，1px细分隔线随鼠标位置丝滑移动；画布占满节点剩余高度，并随节点右下角缩放自动适配横图和竖图。

节点内画布和临时 PNG 只做屏幕显示缩放，不会改变任何 `IMAGE` 输出的宽高，也不会把缩略图送入节点 186。附带工作流只给当前活动的参考图开启实时精确预览，避免两路同时反复请求。

## 安装

把整个 `ComfyUI-SkinBeauty-CN` 文件夹复制到：

```text
ComfyUI/custom_nodes/ComfyUI-SkinBeauty-CN
```

重启 ComfyUI，并强制刷新浏览器页面（`Ctrl+F5`）。基础功能不需要额外安装任何包。

## 可选 MediaPipe 语义蒙版

默认继续使用“自动：已有模型则使用”。它本身就是组合模式：已有MediaPipe和语义模型时，先定位人脸＋身体皮肤，再叠加内置肤色概率约束排除衣服和背景；MediaPipe或模型不可用时才回退到纯 PyTorch/YCbCr 肤色识别。插件不会安装、升级或卸载任何包。

“MediaPipe：允许首次下载”并不是另一套美白算法，它只是在模型文件缺失时允许下载同一个语义模型；模型已经存在时不会重复下载，因此控制台没有下载信息属于正常情况。日常保持默认“自动：已有模型则使用”即可。

需要更稳定地区分皮肤与米色背景时，可选择：

```bash
python -m pip install -r requirements_optional.txt
```

然后在处理节点选择“MediaPipe：允许首次下载”。模型会下载到：

```text
ComfyUI/models/mediapipe/selfie_multiclass_256x256.tflite
```

如果生产环境不能联网，可手工放置该模型。最稳妥的专业用法是连接来自人像分割/手工修正节点的 `MASK`，并选择“仅外部遮罩”。

## 多图与显存建议

- 一个 `IMAGE` 接口原生支持同尺寸批次。
- 不同尺寸的参考图应各用一个处理节点，再共享同一个参数面板；这正是附带 MiniMax 工作流采用的方式。
- 默认逐张处理，避免多个 3K–5K 参考图同时产生大尺寸 Lab 中间张量。
- RTX 5090 32GB 足以处理两路高分辨率参考图；没有必要为几百毫秒的并行收益增加峰值显存。
- “整批并行”只建议用于同尺寸、数量较少且已确认显存余量充足的批次。

## 推荐起点：黄皮转冷白皮

先选“中档·自然冷白”，再根据原图调整：

- 偏黄明显：冷暖 45–65
- 只想提亮：美白 35–55、冷暖 15–35
- 皮肤高光已很亮：高光保护 75–90
- 保留真实毛孔：平滑不高于 15、纹理保留 88–96
- 背景误选：降低肤色识别，或接外部人物皮肤蒙版

## 工作流接法

```text
LoadImage ──> 人物肤色美白｜处理＋预览 ──> 下游参考图输入
参数面板 ────────────────> 处理＋预览（可连接多个）
```

附带 V2.2 工作流已把原节点 137 和 139 的参考图分别经过美白节点后，再送入 MiniMax 节点 186；原有节点模式、文件名和其余接线不变。节点 272 左侧附有完整中文参数说明。

## 设计边界

- 这是可控的色调/质感处理，不是生成式换脸，不会主动重绘五官。
- 轻量肤色识别在米色墙、木材、皮革等区域可能误选；外部语义蒙版的精度最高。
- 独立精确预览只支持能追溯到 `LoadImage` 的输入；即使无法显示，后端节点仍可正常处理任意 `IMAGE` 输入。
- 后端精确预览只允许读取 ComfyUI `input` 目录，拒绝任意路径，避免把服务器文件暴露给前端。
