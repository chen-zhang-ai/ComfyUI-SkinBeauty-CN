# 人物肤色美白｜参数面板

一套参数可同时控制多个“处理＋预览”节点。

- **预设**：低/中/高档或冷白皮、粉润白、奶油白；选择后仍可微调。
- **总强度**：最终效果与原图的混合比例。
- **美白**：主要提升皮肤的 CIELAB 明度。
- **冷暖**：正值减少黄色并偏冷；负值偏暖。
- **红润**：少量增加健康红润感，避免冷白后发青。
- **匀肤**：柔和统一局部明度与色度。
- **暗部提亮 / 高光保护**：打开暗沉区域，同时避免亮部过曝。
- **平滑 / 纹理保留**：控制肤质柔化与毛孔细节之间的平衡。
- **肤色识别 / 蒙版羽化**：控制自动肤色覆盖范围与边缘过渡。

黄皮转冷白皮建议从“中档·自然冷白”开始；高光已经很亮时，提高“高光保护”。
