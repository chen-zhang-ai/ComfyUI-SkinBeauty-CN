# Skin Beauty Settings

One settings node can drive multiple Process + Preview nodes.

- **Preset**: Off, low/medium/high, Cool White Skin, Rosy White, or Creamy White; all remain adjustable.
- **Intensity / Whitening**: overall mix and CIELAB lightness lift.
- **Coolness / Rosy**: reduce yellow or add controlled healthy redness.
- **Evenness / Shadow lift / Highlight protection**: balance skin tone without blowing bright areas.
- **Saturation / Smoothing / Texture preservation**: control chroma and the balance between softness and pore detail.
- **Skin sensitivity / Mask feather**: control automatic coverage and edge transition.

For yellow-to-cool-white correction, start with Medium Natural Cool White and raise highlight protection when the source skin is already bright.
