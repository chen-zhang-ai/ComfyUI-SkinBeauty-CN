# 人物肤色美白｜处理＋预览

输入一张图或一个同尺寸 `IMAGE` 批次，输出美白图、肤色蒙版、同尺寸预览图和中文报告。

## 蒙版

- **自动肤色（推荐）**：内置肤色算法；已有 MediaPipe 时可融合人脸＋身体皮肤语义。
- **外部遮罩优先**：连接上游 `MASK` 后，以外部位置为主并用肤色概率约束。
- **仅外部遮罩**：严格只处理外部蒙版区域，制作正式成片时精度最高。
- **全图调色**：对整张图调色，不做皮肤选择。

“自动：已有模型则使用”已经是MediaPipe人脸/身体位置与内置肤色概率的组合模式，适合作为日常默认。“MediaPipe：允许首次下载”只在模型不存在时开放下载；已有模型时不会重复下载。

## 预览

- 只保留一个“刷新精确预览（不跑视频）”按钮，具有悬停、按压、处理中和完成反馈。
- “实时精确预览”默认开启；调节参数后停止约0.5秒即自动运行后端真实算法，不提交视频队列。
- 已删除可能把背景近似调白的浏览器即时模拟预览。
- 大图占满节点剩余高度；拖动节点右下角即可改变展示区域，并自动适配横图和竖图。
- 在大图中移动鼠标即可丝滑移动1px细分隔线，对比左侧原图和右侧美白结果；不显示遮挡图片的文字标签和圆形手柄。
- 节点内缩放只影响屏幕显示；三个 `IMAGE` 输出均不会被预览逻辑压缩。

## 批次与显存

默认逐张处理，适合 3K–5K 参考图。只有同尺寸图片才能组成一个 ComfyUI `IMAGE` 批次；不同尺寸请使用多个处理节点并共享同一参数面板。
